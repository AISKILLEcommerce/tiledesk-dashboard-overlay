# Risk

## Mode

`overlay`

## Main Risks

- upstream change risk: `medium`
- compliance risk: `low`
- maintenance burden: `medium`
- security risk: `low`

## Mitigations

- `Preserve attribution and keep the enhancement layer separate from upstream source.`
- `Update overlay docs and patches when upstream behavior changes.`

## Review Trigger

Trigger human review if:
- upstream license changes
- upstream project becomes archived
- dependency footprint grows unexpectedly
